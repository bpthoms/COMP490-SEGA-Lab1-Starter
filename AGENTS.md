# COMP 490 Lab 1

## Project Overview

This is a small FastAPI application used to practice
AI-assisted software development.

## Development Guidelines

- Follow Python coding conventions.
- Keep changes small and focused.
- Preserve existing functionality.
- Do not introduce unnecessary dependencies.
- Write automated tests for new functionality.

## Codex Workflow

1. Analyze the codebase before making changes.
2. Explain the proposed implementation.
3. Modify only the necessary files.
4. Run the automated tests.
5. Summarize the changes and test results.
